# 정기그래픽 제작 프로세스 개선안

> **문서 목적**: 현행(As-Is) 워크플로우와 개선 후(To-Be) 워크플로우 비교  
> **작성일**: 2026-03-14  
> **최종 수정**: 2026-03-14 (Ghost API 검증 결과 반영, 기존 스크립트 현황 반영)  
> **대상 업무**: 매주 정기 뉴스레터 그래픽 제작 (인스타그램 카드뉴스)

---

## 1. 업무 개요

| 항목 | 내용 |
|---|---|
| 업무 주기 | 주 1회 |
| 아티클 수 | 5~18개 (매주 변동) |
| 산출물 | 아티클당 4~5장 그래픽 (게시물/스토리) |
| 총 산출물 | 주당 약 50장+ |
| 콘텐츠 유형 | 큐레이션 / 그레이 / 브랜디드 |
| 산출 형식 | PNG/JPG (게시물 1080x1080, 스토리 1080x1920) |

---

## 2. As-Is 워크플로우 (현행)

```
총 소요시간: 2~3시간/주
```

```
노션 DB 확인
    │
    ▼
┌─────────────────────────────────────────────────────────┐
│  STEP 1. 데이터 수집 (수동 반복)            ⏱ 30~60분  │
│                                                         │
│  아티클 1개마다:                                         │
│    1. 노션에서 아티클 링크 클릭                           │
│    2. CMS 페이지 열림 → 전체 내용 복사                    │
│    3. ChatGPT에 붙여넣기                                 │
│    4. 메타데이터 추출 요청 (제목/부제목/에디터/발췌문)      │
│    5. 결과를 엑셀에 복사                                  │
│    6. 대표 이미지 파일 별도 다운로드                       │
│                                                         │
│  ※ 아티클 5~18개를 일일이 반복                            │
└─────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────┐
│  STEP 2. Figma Buzz 일괄 생성 (반자동)       ⏱ 10~15분 │
│                                                         │
│  1. 엑셀 파일을 Figma Buzz에 업로드                      │
│  2. 4개 템플릿 × N개 아티클 = 에셋 일괄 생성             │
│  3. 생성된 에셋을 작업 파일에 복사                        │
└─────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────┐
│  STEP 3. 서문 수동 편집 (핵심 병목)          ⏱ 40~60분  │
│                                                         │
│  아티클 1개마다:                                         │
│    1. 발췌문 분량 보고 2장 vs 3장 판단                    │
│    2. 문장이 끊기지 않는 지점에서 페이지 분리              │
│    3. 각 페이지에서 단어가 끊기지 않게 줄바꿈 조정         │
│                                                         │
│  ※ 가장 시간 소모가 크고 집중력 필요한 단계               │
└─────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────┐
│  STEP 4. 이미지 수동 배치                    ⏱ 20~30분  │
│                                                         │
│  아티클 1개마다:                                         │
│    1. CMS에서 대표 이미지 복사                            │
│    2. Figma 해당 프레임에 붙여넣기                        │
│    3. 크기/위치 조정                                     │
└─────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────┐
│  STEP 5. 내보내기                            ⏱ 10~15분  │
│                                                         │
│  1. 전체 프레임 선택                                     │
│  2. PNG/JPG 다중 사이즈 내보내기                          │
│  3. 파일명 확인 및 정리                                   │
└─────────────────────────────────────────────────────────┘
```

### As-Is 핵심 문제점

| 문제 | 영향 | 심각도 |
|---|---|---|
| 아티클마다 CMS 접속 → 복사 → ChatGPT → 엑셀 반복 | 5~18회 단순 반복, 실수 가능 | 높음 |
| 서문 분할을 감각적으로 판단 | 매번 집중력 소모, 일관성 저하 | 높음 |
| 줄바꿈을 수동으로 조정 | 단순 작업이지만 실수 잦음 | 중간 |
| 이미지를 하나씩 복사-붙여넣기 | 반복 노동 | 중간 |
| 전체 프로세스에 자동화 없음 | 매주 2~3시간 고정 투입 | 높음 |

## 3. To-Be 워크플로우 (개선 후)

```
총 소요시간: 15~25분/주
```

```
노션 DB에서 URL+콘텐츠유형 복사 → urls.txt (2분)
    │
    ▼
┌─────────────────────────────────────────────────────────┐
│  STEP 1. 스크립트 실행 (자동)                  ⏱ ~5분   │
│                                                         │
│  $ python generate_graphics.py --issue 231              │
│                        --input urls.txt                  │
│                                                         │
│  자동 처리:                                              │
│    ├── Ghost Content API로 메타데이터 일괄 수집           │
│    │   (제목, 에디터명, 대표이미지, 본문 HTML)             │
│    ├── HTML 본문에서 서문용 발췌문 자동 추출               │
│    │   (custom_excerpt는 부제목용으로만 사용)              │
│    ├── Claude Haiku로 서문 자동 분할 (2장 또는 3장)       │
│    │   (줄바꿈, 단어 끊김 방지 포함)                      │
│    ├── 대표 이미지 자동 다운로드 + XLSX 셀 삽입           │
│    └── Buzz용 XLSX 자동 생성                             │
│                                                         │
│  [3/12] 큐레이션 3 처리 중... ← 진행률 실시간 표시       │
│  완료! 정기그래픽_231호.xlsx 생성                         │
│  API 비용: $0.01 (12 아티클)                             │
│                                                         │
│  ※ CMS 접속, ChatGPT 복붙, 수동 엑셀 작성 전부 제거     │
│  ※ 콘텐츠 유형은 Ghost API에 없어 urls.txt에서 입력      │
└─────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────┐
│  STEP 2. Figma Buzz 일괄 생성 (기존과 유사)    ⏱ 5분    │
│                                                         │
│  1. 생성된 XLSX를 Figma Buzz에 업로드                    │
│  2. 템플릿 × N개 아티클 = 에셋 일괄 생성                 │
│     (서문 3장 + 이미지 포함하여 한 번에 생성)             │
│  3. 작업 파일에 복사                                     │
│                                                         │
│  ※ 서문 분할, 이미지 배치가 이미 완료된 상태              │
└─────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────┐
│  STEP 3. 검수 및 미세 조정 (수동)             ⏱ 5~10분  │
│                                                         │
│  1. 서문 줄바꿈이 자연스러운지 훑어보기                   │
│  2. 이미지 위치/크기 미세 조정 (필요 시)                  │
│  3. 특이 케이스 수동 보정 (전체의 ~10%)                   │
└─────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────┐
│  STEP 4. 내보내기 (기존과 동일)               ⏱ 5~10분  │
└─────────────────────────────────────────────────────────┘
```

## 6. 기술 검증 현황

> 2026-03-14 기준

| 검증 항목 | 결과 | 비고 |
|---|---|---|
| Ghost Content API 동작 | ✅ 정상 | 키 `508bef...` 유효, title/authors/html/feature_image 반환 |
| Ghost excerpt 필드 | ✅ 확인 | `custom_excerpt`는 부제목용(짧음), 서문은 html 본문에서 추출 |
| 콘텐츠 유형 구분 | ⚠️ Ghost 불가 | tags에 CURATION/GRAY/BRANDED 없음 → urls.txt에서 수동 입력 |
| 스크립트 초안 | ✅ 작성됨 | `generate_graphics.py` 329줄, 수정 보완 필요 |
| 서문 분할 기준 | ✅ 확정 | 3개 호 34개 아티클 실데이터 분석 완료 |
| Buzz XLSX 이미지 인식 | ⬜ 미검증 | openpyxl 이미지 셀 삽입 → Buzz 인식 테스트 필요 |
| Buzz 서문 3개 템플릿 | ⬜ 미검증 | 발췌문_1/2/3 템플릿 확장 후 동작 확인 필요 |
| Claude API 연동 | ⬜ 미검증 | ANTHROPIC_API_KEY 접근 문제 해결 필요 |
