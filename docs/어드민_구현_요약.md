# 정기그래픽 자동화 — 어드민 웹 UI 구현 요약

> **프로젝트**: AntiEgg 매거진 주간 인스타그램 카드뉴스 자동 생성
> **목표**: 수작업 2~3시간 → 어드민 UI에서 10분 내 완료
> **기간**: 2026-03-26 ~ 2026-03-28
> **월 비용**: $0 (Ghost API 무료 + Claude Code 구독 포함)

---

## 1. 시스템 아키텍처

```
┌─────────────────────────────────────────────────────────────┐
│  어드민 UI (Next.js 16, Vercel 배포)                         │
│                                                             │
│  시작 → 순서 편집 → 뉴스레터+아티클 편집 → 추출              │
├─────────────────────────────────────────────────────────────┤
│  API Layer (Next.js API Routes)                             │
│  ├── /api/fetch-articles     ← Notion DB + Ghost CMS       │
│  ├── /api/fetch-newsletter   ← Slack 메시지 자동 파싱       │
│  ├── /api/process-text       ← 규칙 기반 서문 분할          │
│  ├── /api/export             ← Playwright PNG → ZIP         │
│  └── /api/export-single      ← 개별 이미지 PNG 추출         │
├─────────────────────────────────────────────────────────────┤
│  외부 서비스 연동                                            │
│  ├── Notion API  ← 아티클 목록 (상태 기반 필터)              │
│  ├── Ghost CMS   ← 아티클 메타데이터 + 서문 추출            │
│  ├── Slack API   ← 뉴스레터 제목/서문 자동 수집             │
│  └── Playwright  ← headless Chromium PNG 캡처               │
└─────────────────────────────────────────────────────────────┘
```

## 2. 워크플로우

### AS-IS (수작업)

```
CMS 접속 → ChatGPT 복붙 → 엑셀 정리 → Figma 수동 배치 → 수동 export
소요: 2~3시간/주, 아티클 5~18개 × 4~5장 = 주당 50장+
```

### TO-BE (어드민 UI)

```
1. 호수 입력 → "제작 시작"                              ← 30초
   Notion DB에서 아티클 자동 수집 + Ghost에서 메타데이터 추출
   서문 분할/제목 2줄 자동 처리 완료 상태로 로드

2. 순서 편집 (드래그 앤 드롭)                            ← 1분
   유형별(큐레이션/그레이/브랜디드) 그룹 내 순서 변경

3. 뉴스레터 편집                                         ← 1분
   Slack에서 제목/서문 자동 불러오기 (버튼 1회)
   실시간 미리보기로 확인

4. 아티클 편집                                           ← 3분
   제목 2줄/부제목 2줄/서문 페이지 수정
   iframe 실시간 미리보기로 즉시 확인
   화살표로 순차 이동 (뉴스레터 → 아티클1 → ... → 9)

5. 전체 추출 (ZIP)                                       ← 2분
   Playwright로 PNG 일괄 렌더링
   아티클 카드 + 뉴스레터 미리보기/스토리 + 마지막장

총 소요: ~8분
```

## 3. 핵심 기능

### 3-1. 데이터 자동 수집

| 데이터 | 출처 | 방식 |
|--------|------|------|
| 아티클 목록 | Notion DB | `상태=그래픽 이미지 작업` 필터 |
| 제목/부제목/에디터/히어로이미지/서문 | Ghost CMS | Content API slug 기반 |
| 서문 분할 (2~3페이지) | 규칙 기반 | 300자 기준 문장 경계 분할 |
| 제목/부제목 2줄 | 규칙 기반 | 의미 단위 줄바꿈 |
| 뉴스레터 제목/서문 | Slack | `1-팀-콘텐츠` 채널 메시지 파싱 |

### 3-2. 실시간 미리보기

- iframe `srcdoc` 방식으로 API 왕복 없이 즉시 렌더링
- 텍스트 수정 시 300ms 디바운스 → 미리보기 자동 갱신
- 서문 textarea 포커스 시 해당 서문 페이지로 미리보기 자동 전환

### 3-3. 템플릿 (Figma 디자인 기반)

| 템플릿 | 사이즈 | 용도 |
|--------|--------|------|
| 스토리 표지 | 1080×1920 | 아티클 인스타 스토리 |
| 게시글 표지 | 1080×1350 | 아티클 인스타 게시물 (상단/하단 모드) |
| 발췌문 페이지 | 1080×1350 | 아티클 서문 2~3장 |
| 뉴스레터 미리보기 표지 | 1080×1350 | 뉴스레터 타이틀 카드 |
| 뉴스레터 미리보기 서문 | 1080×1350 | 뉴스레터 서문 (**볼드** 강조 지원) |
| 뉴스레터 미리보기 아티클 | 1080×1350 | 아티클별 뉴스레터 카드 |
| 뉴스레터 스토리 표지 | 1080×1920 | 뉴스레터 스토리 (제목+서문+발행인) |
| 뉴스레터 스토리 목록 | 1080×1920 | 아티클 목록 (8개/장, 자동 페이지 분할) |

### 3-4. 추출

- **전체 추출**: Playwright PNG 일괄 렌더링 → archiver ZIP → 브라우저 다운로드
- **개별 추출**: 썸네일 그리드에서 개별 카드 PNG 다운로드
- **마지막장 자동 포함**: 해당 유형(큐레이션/그레이/브랜디드) 아티클 존재 시 자동 포함
- **Notion 상태 자동 업데이트**: 추출 완료 시 `그래픽 이미지 작업` → `웹사이트 업로드`

## 4. UI 구성

```
┌──────┬──────────────────────────────────────────────┐
│      │ [←→] [뉴스레터] [큐레이션 1~9] [그레이 1]  [추출→] │
│ 233호 ├──────────────────┬───────────────────────────┤
│      │ [스토리][표지]    │  제목(2줄)  │  서문1      │
│ 순서  │ [NL미리보기]     │  부제목     │  서문2      │
│ ● 편집│ [서문1][서문2]   │  에디터     │  서문3      │
│ 추출  │                  │  제목위치   │             │
│      │  [미리보기]       │  이미지위치 │             │
│      │                  │ [자동분할] [초기화]        │
└──────┴──────────────────┴───────────────────────────┘
```

- **좌측 사이드바**: 호수/날짜 + 순서→편집→추출 단계
- **상단 통합 내비게이션**: 화살표 + 넘버 필로 뉴스레터↔아티클 순차 이동
- **좌측 미리보기**: 페이지 타입별 탭 전환
- **우측 편집 패널**: 2열 레이아웃 (메타데이터 | 서문)
- **localStorage 자동저장**: 작업 중단 후 복원 가능
