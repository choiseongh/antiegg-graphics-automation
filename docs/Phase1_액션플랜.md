### 0-1, 0-2 검증 결과 (2026-03-14 확인)

```
Ghost Content API: 정상 동작
  - 엔드포인트: https://square.antiegg.kr/ghost/api/content/posts/
  - 키: 508bef5f0005054b991088cd38 (유효)
  - title, authors, feature_image, html, tags 모두 정상 반환
```

**발견된 이슈 2가지:**

#### 이슈 A: `custom_excerpt`는 발췌문이 아님

| 포스트 | custom_excerpt 내용 |
|---|---|
| 두산아트랩 전시 2026 | `"박예림."` ← 작가명만 |
| 만질 수 있는 조각들 | `"김보경, 김영서, ..."` ← 참여 작가 나열 |
| 멈춘 자리에서 피어난 통찰 | `"안규철, 에마 미첼, 존 버거처럼 관찰하기"` ← 부제목 수준 |

→ **결론: 서문용 발췌문은 `html` 본문에서 BeautifulSoup으로 추출해야 함**  
→ 기존 스크립트의 `extract_intro()` 로직 방향은 맞음, 실데이터 품질 검증 필요

#### 이슈 B: 콘텐츠 유형(CURATION/GRAY/BRANDED) 구분 불가

tags에는 장르(`아트`, `컬쳐`)만 있고, 콘텐츠 유형 구분이 없음.

→ **결론: urls.txt 입력 시 유형을 같이 기입하는 방식으로 해결**  
→ 기존 스크립트의 `extract_content_type()` 수정 필요

### 판단 분기점

```
0-3 실패 → 이미지는 수동 유지. 텍스트만 자동화 (여전히 큰 시간 절약)
0-4 실패 → 서문 분할은 XLSX에 넣되, Buzz 1회 실행 후 수동 복붙
0-5 실패 → .env 파일 + python-dotenv로 우회 (스크립트에 로딩 코드 추가)
```
